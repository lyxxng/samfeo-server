# SAMFEO and SAMFEO++ Web Server

Web server for [SAMFEO](https://github.com/shanry/SAMFEO/tree/samfeo_prec#) & [SAMFEO++](https://github.com/shanry/FastDesign/tree/main#) RNA design. Access the server at the following site: https://linearfold.eecs.oregonstate.edu/samfeo

Cite the following paper for SAMFEO:
Tianshou Zhou, Ning Dai, Sizhen Li, Max Ward, David H. Matthews, and Liang Huang (2023). [RNA design via structure-aware multifrontier ensemble optimization](https://academic.oup.com/bioinformatics/article/39/Supplement_1/i563/7210514). *Bioinformatics*, 39(Supplement_1), i563-i571.
